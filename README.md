## Консоль как язык

Терминал — это полноценный язык для общения с компьютером. Вы даёте системе «глаголы» (программы) и «аргументы» (объекты и параметры), а она отвечает.

``` shell
~ $ ./ascii-art "Hello, world!" --color --align=center
```
`./ascii-art`: глагол (что сделать)

`"Hello, world!"`: объект (с чем сделать?)

`--color --align=center`: параметры (как сделать?)

## Руководства `man` и `apropos`

- `man <программа>` — подробный справочник по команде и её опциям.
- `apropos <ключевое_слово>` или `man -k <ключевое_слово>` — ищет по описанию.

> Более современный способ — искать нужный синтаксис через Google или спросить LLM.

## Всё является файлом

В Linux/Unix практически всё выглядит как файл: устройства, процессы, сокеты, обычные файлы. Это упрощает работу — единый интерфейс.
Например, я могу вывести температуру процессора просто поискав папку в нужном месте

``` shell
akim@arthur-Surface-Pro-:~$ cat /sys/class/thermal/thermal_zone0/temp
37000
```
Теперь я знаю, что температура 37 градусов.
В Unix, в файлах можно найти практически любую информацию, главное знать, где этот файл найти.

## Абсолютные и относительные пути

- **Абсолютный путь:** начинается от корня `/home/user/docs/doc.txt`.
- **Относительный путь:** от текущей директории `docs/doc.txt`.

Люди устали каждый раз писать длинные абсолютные пути — появились относительные.
Чтобы посмотреть текущую директорию, можно написать `pwd`, а чтобы её поменять, написать `cd <dirname>`. Каждый раз использовать `cd` чтобы получить доступ к файлу не обязательно, можно просто указать относительный путь.
Например, вместо

``` shell
cd Downloads
cd math-skills
cd cmd
go run main.go
```
можно написать

``` shell
go run Downloads/math-skills/cmd/main.go
```

## Тильда для домашней папки

Вместо полного пути к своему домашнему каталогу (`/home/user`) можно писать `~`.
`cd ~/Downloads` это то же самое, что `cd /home/user/Downloads`

## Ввод и вывод как файлы

У каждой программы есть stdin (ввод) и stdout (вывод). В программе, написанной на Go, ввод можно прочитать через `bufio.Scanner(os.Stdin)`, а вывод делается через `fmt.Print()`

## Пайплайны (`|`)

Пайп передаёт вывод одной программы на вход другой. Например, вот задание с бассейна [quest01/cl-camp6](https://github.com/01-edu/public/tree/master/subjects/cl-camp6):

``` sh
find . -type f -o -type d | wc -l
```
`find` пишет в `stdout` список всех файлов в папке и её подпапках, а `wc -l` считает их количество.

Переменные можно записывать, просто указав название и новое значение через знак равенства:

## Кавычки: одиночные vs двойные

- **Одинарные ****`'...'`** — всё внутри берётся буквально.
- **Двойные ****`"..."`** — разрешают подстановку переменных и подстановку команд.

```sh
echo '$interview_number'   # выводит $HOME
echo "$interview_number"  # выводит какое-то число
```

---

## Перенаправление

- `>` — создать или перезаписать файл.
- `>>` — добавить в конец файла.

```sh
echo "тест" > out.txt
cat out.txt # выводит тест
echo "test" >> out.txt # выводит "тест" на одной строчке и "test" на второй
```

## Обработка ошибок и цепочки

- `&&` — следующая команда выполняется только при успехе.
- `||` — при ошибке.
- `;` — независимо.

```sh
mkdir новая && cd новая || echo "не удалось"
# если не получилось создать папку и в неё зайти, вывести на экран "не удалось"
```

## Переменные окружения

Переменные передают контекст: `$PATH`, `$HOME`, `$USER` и т. д.

```sh
echo $PATH
echo $USER
export MY_VAR=значение
echo $MY_VAR
```
Если записать свои переменные окружения в bash_profile или zshrc, они станут доступны всем программам.

## Простые скрипты на Bash

```sh
echo 'echo Hello, world!' > hello.sh
bash ./hello.sh
```

**Но** для больших скриптов (>10 строк) лучше использовать полноценные языки (например, Python), чтобы не нырять в синтаксис каждой утилиты.

### Примеры: sed, awk, cut

- `sed` — потоковый редактор:
  ```sh
  echo "foo bar" | sed 's/foo/baz/' # выводит 'baz bar' потому что заменил foo
  ```
- `awk` — обработка полей:
  ```sh
  echo -e "a b c\nd e f" | awk '{print $2}' # выводит b e, потому что запросили второе поле
  ```
У каждой утилиты свой неповторимый синтаксис, поэтому лучше не тратить много времени на изучение их всех, а использовать по нужде.

## Настройка шелла через `.bash_profile`

Файл `.bash_profile` или `.bashrc` (в зависимости от дистрибутива и используемой оболочки) позволяет настраивать поведение командной строки под себя. Вот несколько полезных идей:

* **Алиасы** — сокращения для часто используемых команд:

  ```bash
  alias ll='ls -lhAF'
  alias gs='git status'
  alias commit='git commit -am'
  alias cat=bat # bat - альтернатива cat на языке Rust
  ```

* **Функции** — для более сложных действий:

  ```bash
  mkcd() {
    mkdir -p "$1" && cd "$1"
  }
  ```

* **Включить автодополнение и исправление опечаток:**

  ```bash
  shopt -s cdspell
  shopt -s autocd
  ```

После изменения `.bash_profile` или `.bashrc` перезапустите терминал чтобы применить настройки.

## Полезные хоткеи Readline

Редактировать командную строку можно очень эффективно с помощью встроенных сочетаний клавиш:

* `Ctrl + A` — перейти в начало строки.
* `Ctrl + E` — перейти в конец строки.
* `Alt + B` — переместиться на одно слово влево.
* `Alt + F` — переместиться на одно слово вправо.
* `Ctrl + U` — удалить всё от курсора до начала строки.
* `Ctrl + K` — удалить всё от курсора до конца строки.
* `Ctrl + W` — удалить предыдущее слово.
* `Ctrl + Y` — вставить последнее удалённое.
* `Ctrl + R` — интерактивный поиск по истории команд.
* `Ctrl + L` — очистить экран (аналог `clear`).
* `Ctrl + /` — отменить последнее изменение (как `Ctrl+Z` в других программах).

> Эти сочетания работают в большинстве шеллов, включая Bash и Zsh.
